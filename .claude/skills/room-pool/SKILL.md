# 방 사진 풀 만들기

팀이 모은 방 사진 폴더를 검색 페이지용 풀로 바꾼다. 결과물은 두 개다.

- `room_pool.zip`: `pool.csv` + `photos/*.jpg`(긴 변 1600px). 검색 페이지 관리 화면의 "풀 불러오기"로 그대로 넣는다.
- `pool.csv`: 열은 `file, tags, contains`. tags는 `;`로 구분하고, contains는 비워 둔다(풀은 처음부터 타깃 요소가 없는 사진으로 채우기 때문).

## 준비

Pillow 11.3 이상이 필요하다(AVIF를 읽으려면). 없거나 낮으면 `pip install -U "pillow>=11.3"`(필요하면 `--break-system-packages`)로 설치한다. 받는 형식: jpg, jpeg, jfif, png, webp, avif.

## 순서

이 스킬 폴더 경로를 `SKILL_DIR`이라 부른다. 작업 폴더는 사용자가 따로 말하지 않으면 사진 폴더 옆에 `<사진폴더이름>_pool_work`로 만든다.

### 1. 확인용 시트 만들기

```bash
python "$SKILL_DIR/scripts/make_sheets.py" "<사진폴더>" "<작업폴더>"
```

사진을 6장씩 묶은 `sheets/sheet_NN.jpg`와 번호→파일명 표 `index.json`이 생긴다. 하위 폴더, `__MACOSX`, 숨김 파일은 알아서 건너뛴다. 같은 이름의 사진이 있으면 멈추니, 사용자에게 이름을 바꿔 달라고 한다.

### 2. 시트를 보고 태그 달기

`sheets/`의 시트를 Read 도구로 하나씩 열어 본다. 사진 왼쪽 위의 `#번호`가 `index.json`의 번호다. 시트 한 장을 볼 때마다 `tags.json`에 그 6장의 태그를 바로 적어 둔다(긴 작업이 끊겨도 이어 갈 수 있게).

```json
{
  "1": ["침실", "원룸", "화이트", "미니멀", "밝은", "햇살", "책상"],
  "2": ["거실", "소파", "우드", "내추럴", "큰창문", "리버뷰"]
}
```

태그 규칙:

- 사진마다 6~10개.
- `$SKILL_DIR/vocab.json`의 어휘를 먼저 쓴다. 이 어휘는 검색 페이지에서 영어 검색어(cozy, white, bedroom 등)와도 연결된다.
- 반드시 넣을 것: 방 종류 1개 이상(침실·원룸·작은방·거실 등), 색·톤·빛 2개 이상(화이트·우드·베이지·밝은·햇살·노을·야경 등), 분위기 1~2개(아늑한·미니멀·모던·북유럽·빈티지 등).
- 보이는 것만: 가구·구성(책상·소파·책장·옷장·거울·커튼·큰창문), 전망·특징(시티뷰·리버뷰·벽난로·사진벽·곡선).
- 어휘에 없는 말이 꼭 필요하면 짧은 한국어 명사로 쓴다. 이런 태그는 한국어로만 검색된다.
- 사람이 검색창에 칠 법한 말 위주로 붙인다. 사진에 없는 것은 붙이지 않는다.

시트를 보다가 타깃 요소(화분 식물, 러그, 스탠드 조명, 벽에 건 그림·액자·포스터, 따뜻한 노란 간접 조명)가 또렷이 보이는 사진이 있으면, 태그와 별도로 `flags.json`에 적는다. 이 풀은 타깃 요소가 없어야 하므로 팀이 직접 확인하고 뺄 사진들이다.

```json
{ "12": "창가에 화분 식물", "31": "바닥에 러그, 벽에 액자" }
```

### 3. ZIP과 CSV 만들기

```bash
python "$SKILL_DIR/scripts/build_pool.py" "<사진폴더>" "<작업폴더>"
```

태그가 빠진 사진, 어휘 밖 태그, `flags.json`의 사진을 출력해 준다. 태그가 빠진 사진이 있으면 2단계로 돌아가 채운 뒤 다시 실행한다.

### 4. 사용자에게 알리기

짧게 알린다: 사진 수, ZIP과 CSV 위치, 확인이 필요한 사진(flags) 목록과 이유. 넣는 방법은 "검색 페이지 관리 화면 → 풀 불러오기 → room_pool.zip"이라고 한 줄로 덧붙인다. 이전 풀이 들어 있으면 "전체 삭제" 후 불러오라고 안내한다.

## 이어서 할 때

사진을 더 모았으면 같은 작업 폴더로 1단계부터 다시 돌린다. 번호가 바뀔 수 있으니, 기존 `tags.json`은 파일명 키로 바꿔 두거나(`index.json`으로 번호→파일명 변환) 새 사진만 태그한다. `build_pool.py`는 번호 키와 파일명 키를 모두 받는다.
