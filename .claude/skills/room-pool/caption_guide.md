# 방 사진 설명문 작성 규칙 (검색용, 참여자에게 보이지 않음)

목적: 검색 도구가 태그(95개 단어) 밖의 말로도 사진을 찾을 수 있게, 사진마다 보이는 것을 적는다.
연구 맥락: 타깃 요소 D(식물, 러그, 스탠드 조명, 벽 그림, 겹친 침구·담요)의 노출을 비교하는 실험이다. 설명문이 D를 더 자세히·더 자주 적으면 D 사진이 검색에 더 잘 걸려 실험이 기울어진다. 그래서 D를 다른 물건과 **똑같은 무게**로 적는다(보이면 이름만 한 번, 꾸밈말 없음).

## 열 (CSV, UTF-8, 머리글 포함)
`file,caption,objects,flags,note`
- `file`: 사진 파일 이름 그대로
- `caption`: 한국어 1–2문장, 40–90자. 보이는 것만. 방 종류(침실/원룸/거실 등), 큰 가구, 주요 색·재료, 빛(자연광/저녁 조명), 눈에 띄는 물건.
  - 평가·감성 형용사 금지: 아늑한, 예쁜, 감성적인, 세련된, 고급스러운, 따뜻한 분위기 등 (분위기 태그는 이미 따로 있다). 색·재료·형태 같은 관찰 가능한 말만.
  - D 요소는 보이면 물건 이름만 적는다(예: "화분", "러그", "스탠드", "액자", "담요"). 크기·개수·위치를 D에만 자세히 적지 않는다.
- `objects`: 보이는 물건 명사를 `;`로 구분, 5–15개. 일상어 + 흔한 외래어로 (예: 철제 침대 프레임; 빈백; 피아노; 벽난로; 행거; 전신 거울; 블라인드; 모니터). 보이는 것은 D든 아니든 빠짐없이 같은 방식으로 적는다.
- `flags`: 해당하면 `;`로 구분, 없으면 빈칸
  - `watermark:<보이는 글자>` (예: watermark:小红书, watermark:tiktok @…, watermark:오늘의집)
  - `render_suspect` (3D 렌더처럼 보임), `ai_suspect` (AI 생성처럼 보임: 이상한 물체, 뭉개진 글자, 비현실적 반복)
  - `not_room` (방 사진이 아님), `collage` (여러 장 합친 이미지), `low_quality` (흐림·저해상도)
- `note`: 판단이 애매한 점만 짧게

## 형식
- 쉼표가 들어간 칸은 큰따옴표로 감싼다. 한 줄 = 사진 한 장.
- 50장 모두, 받은 목록 순서대로.

## 예
`0f66c….jpg,"원목 저상형 침대와 베이지 침구가 있는 좁은 원룸. 창가에 흰 커튼과 작은 책상, 바닥에 화분이 있다.",저상형 침대;베이지 침구;흰 커튼;책상;의자;화분;펜던트 조명;원목 바닥,,`
